A Agência Experimental de Software (AES) é uma organização estudantil ligada ao curso de Engenharia de Software da PUC Minas, que desenvolve soluções digitais reais para clientes internos e externos da universidade. A landing page institucional é o ponto de entrada dessa operação: é por ela que novas demandas chegam, são analisadas e encaminhadas para as equipes responsáveis, e também onde a agência mostra os projetos já entregues.

## Meu papel

Atuei no backend do site, construindo a API em Node.js e Express com Prisma sobre PostgreSQL, incluindo o fluxo de e-mails automáticos (via Nodemailer) que confirma ao cliente o recebimento da demanda e, depois, avisa quando ela é aprovada como projeto.

## Funcionalidades

- Formulário de contato para empresas e alunos interessados em propor ou entrar em um projeto
- Página de especialidades, destacando os diferenciais da agência (entrega no prazo, personalização, stack moderna)
- Vitrine de projetos entregues pela agência
- FAQ segmentado para dois públicos diferentes: empresas clientes e alunos que querem participar
- Fluxo de e-mail automático que confirma o recebimento de uma demanda e, depois, sua aprovação como projeto
